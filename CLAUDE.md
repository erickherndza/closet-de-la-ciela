SUBID# El Closet de la Ciela — demo redesign

Static multi-page demo of the redesign of https://elclosetdelacielausa.com (Shopify store). Plain HTML/CSS/JS, no framework, no build step needed to view it. Language of the site: English. Language with the owner (Erick): Spanish.

- Repo: https://github.com/erickherndza/closet-de-la-ciela (branch `main`)
- Live demo for the client (GitHub Pages): https://erickherndza.github.io/closet-de-la-ciela/
- Pushing to `main` redeploys the demo in 1–2 minutes.

## Structure

```
index.html  shop.html  collections.html  necklaces.html  rings.html
about.html  contact.html  product.html     ← GENERATED, see below
css/styles.css      all styles (tokens in :root at the top)
js/main.js          header/nav/search, announcement bar, hero slider, product lists + filters, product page, forms
js/products.js      catalog snapshot (67 products) from the live store; sets window.PRODUCTS and window.STORE_URL
images/             logo, hero, lifestyle photos, collections, products/{handle}-{n}.webp
tools/build_pages.py   generator for every .html page
_archive/           original single-file bundle and original loose images (reference only)
```

## Editing pages

The 8 HTML files are generated by `tools/build_pages.py` (header, footer and all page content live in that script). **Edit the script and run `/opt/homebrew/bin/python3.12 tools/build_pages.py`** (the system `python3` is 3.9 and fails on an f-string; needs ≥ 3.12), not the HTML files, or the next build overwrites the change. CSS and JS are edited directly.

## Home "About us" section

Two columns: copy on the left, `images/about-seal.webp` (client's teal circular seal "El Closet de la Ciela · Since 2013", transparent PNG→webp, cropped by design) on the right, flush to the right edge of the viewport (`.about-home` has no right padding). Title "About us" uses the same `.h2` style as every other home title (Cormorant, light, sentence case): a bold wide-caps Syncopate title was tried and rejected as off-brand. Then the paragraph (Jost), pink rule, quote in Cormorant italic, ghost button "Discover our story". Markup in `tools/build_pages.py` (`#story`), styles `.about-home/.about-text/.about-quote/.about-photo` in `css/styles.css`. Client copy: "At El Clóset de la Ciela…" (since 2013, Angelina Flores 'La Ciela', Dominican Republic, ships worldwide) and the quote "More than accessories, we deliver small treasures wrapped in a unique shopping experience."

## Design tokens

Deep teal `#1E5468` (text, buttons), accent `#7FD6D3`, pop pink `#E0559A`, mint `#CFE6E3`, background `#F7FBFA`. Fonts (Google Fonts): Cormorant Garamond (display), Jost (body), Syncopate (labels, uppercase, wide tracking). Header is light because the logo (`images/logo-closet-de-la-ciela.webp`, teal on transparent, only 180×46) is not legible on a dark background; the footer shows it white via a CSS filter.

## How things work

- **Hero slider** (`.hs`): 4 slides, crossfade, autoplay 6.5 s, dots/arrows/swipe/keyboard. Uses delegated listeners on `document` on purpose (survives re-renders). Slide 1 is the full-bleed campaign photo with its text baked in; on mobile it is shown `contain` over a gradient so the text is not cropped.
- **Products**: cards are rendered by JS from `window.PRODUCTS` (`[data-products]` containers with `data-category`, `data-collection`, `data-limit`). `shop.html` filters by category, collection, stock, sort and text; URL params `?category=`, `?collection=` (`gold|silver|new`), `?q=`.
- **Product page**: `product.html?p={handle}` renders gallery, options, price and related items. "Add to bag" opens the live store cart with the variant: `https://elclosetdelacielausa.com/cart/{variantId}:{qty}`. Checkout happens in Shopify; the demo does not process payments.
- **Header icons** (account, bag) and footer policy links point to the live store.
- **Forms** (newsletter, contact) only validate client-side; nothing is sent yet.
- Categories (`necklaces|earrings|bracelets|rings`) are derived from product titles because the store has no product types. Collections come from the store's `/collections/{handle}/products.json`; the "Best Seller" collection is empty there, so the "All Jewelry" card replaces it.

## Refreshing the catalog

Data is a snapshot. To refresh: fetch `https://elclosetdelacielausa.com/products.json?limit=250` (plus `/collections/{handle}/products.json` for `14k-18k-gold`, `925-sterling-silver`, `new-arrivals`), download up to 5 images per product at `?width=900`, convert to webp (~800 px wide, q≈78) as `images/products/{handle}-{n}.webp`, and rewrite `js/products.js` keeping the same fields (`handle, title, price, available, category, collections, img, img2, images, options, variants, html, desc`). Description HTML is whitelisted to `p, ul, li, br, strong, em, b, i`.

## Shopify theme (`shopify-theme/`)

Online Store 2.0 theme ported from the demo. Store admin `https://admin.shopify.com/store/elclosetdelacielausa`. The public theme (`valoon-theme REBRAND`, id `182385770813`) is untouched; **never publish a theme without Erick asking**. v7 obsolete, v8 = base design.

- **Current client version: `closet-de-la-ciela-redesign-v12`** (unpublished; v9 deleted) = v8 + sharp header logo (450×123 PNG→webp), About section with the full circular logo (`about-logo.webp`, centered on mobile), rainbow slide photo padded to show complete, + the About section (client seal image, flush right) (`sections/brand-story.liquid`, `templates/index.json`, CSS at the end of `assets/theme.css`, `assets/about-seal.webp`) + bold header menu (`.main-nav a{font-weight:700}`, also in the demo CSS). Preview (no login): `https://elclosetdelacielausa.com/?preview_theme_id=193260355901&pb=0`. Each upload creates a new id, so update this line after every upload.
- **Delivery**: `cd shopify-theme && zip -rq ../closet-de-la-ciela-redesign-vN.zip . -x ".DS_Store"`, then **Erick uploads it** (Online Store → Themes → Import → Upload zip). Claude cannot attach files in that dialog and `shopify theme push` fails (CLI account has no store access). Zips are git-ignored.
- **Before zipping**: `python3 tools/check_theme_json.py` and `shopify theme check --path shopify-theme` (3 expected Google Fonts warnings).
- **Preview errors**: "Theme cannot be previewed because it's missing layout/theme.liquid, config/settings_schema.json" (or "El tema especificado no existe" in the editor) means that theme id no longer exists (replaced/deleted), not a bad zip. The themes list can show a stale row, so read the id from the editor URL after clicking "Editar tema". If the client sees an old version, try a private window / hard reload (preview cookie).
- **Get the preview id**: Themes page, wait ~8 s, screenshot before clicking (layout shifts; a misclick opened the public theme's editor), "Editar tema" on the draft row, read `/themes/{id}/editor` from the URL.
- **Gotcha (v9, 2026-10-24)**: a 492-char richtext in `templates/index.json` made the home return 404 (editor showed "Página 404"); Shopify silently drops the template. Keep setting values short (<255 chars; the paragraph is split in `text_1..3`) and no `"default": ""`. External URL defaults in section schemas also drop the section.
- **Do not publish as is**: public theme has features this one lacks: accelerated checkout buttons (`payment_button`), installments message (`payment_terms`), JSON-LD (`Organization`, `WebSite`, `Product`, `BreadcrumbList`) and cart extras (order note, coupon note, secure-shopping badge). Ship them in one later zip after the client's corrections.
- Forms and checkout were not submitted on purpose; test them with an own email before publishing.
